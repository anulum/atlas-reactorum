# Atlas coverage ledger

This ledger defines observable completion criteria. Counts are inventory counts, not percentages of all reactors worldwide. The project remains an expanding research atlas. Counts below refer to retained input tables and integrated bundles; their
source dates remain per record. This is not a fresh verification of physical
facilities or operating status.

| Layer | Acceptance criterion | Outstanding work |
|---|---|---|
| Reactor taxonomy | Every entry has an identity, family, principle, evidence scope and source; synonyms do not inflate counts | All 135 entries have historical classification/source-scope records and 599 claim citations with locators; 480 citations bind all 405 physical fields. Complete entry review and maturity/evidence classification remain pending. Review family coverage and distinguish configurations, fuels, scale classes and applications |
| Power facilities | Separate site and unit identities; dated status and provenance | 1,823 open unit records are integrated; reconcile consequential fields against PRIS, national regulators and operators; the WRI layer remains separate plant-level data |
| Research reactors | Compare coverage with an authoritative dated registry | 172 records have 54 exact-ID overlays across five passes; 96 operator, 117 purpose and 145 first-criticality fields remain empty. Broader public-source ingestion and reconciliation remain incomplete |
| Fusion facilities | Cover magnetic, inertial, magneto-inertial and alternative devices with dated source records | The default uses 174 dated IAEA FFDB records, including 137 publisher map points, and six separate supplemental records. The optional historical selection retains six compilation fields for 146 identities, with 11 separately sourced additions and 40 overlay rows targeting 34 devices. Exact device coordinates, current operating status and worldwide coverage require further verification; the complete historical bundle has its own explicit input and rights boundary |
| Companies | Identity, aliases, jurisdiction, approach, devices, status, dated sources and independently assessed claims | 98 company/programme screening records and 39 exact-name depth overlays are integrated; the latest ten profiles carry 33 dated citations and explicit source-role and prototype-fuel limits. Technical and corporate verification remains incomplete because status, funding and announcements change |
| Chemical/biochemical | Taxonomy coverage plus explicitly scoped public facility inventories | EEA/EPA layer is integrated; no known exhaustive global equipment register, so add country/sector inventories and disclose reporting thresholds without inferring vessel counts |
| Literature | Traceable metadata, access status, local-file integrity and claim-level citations | Discovery candidates require review before promotion to the primary bibliography |
| Interface | Search, family/evidence filters, meaningful comparison, selectable map points and source navigation work with full local datasets | Browser interaction and keyboard checks after each substantive release |
| ANULUM integration | Dated public-repository metadata, explicit role and evidence boundary, refreshable without hand editing | Thirty reactor-ecosystem repositories are catalogued; future GitHub integration should preserve per-repository licences and never convert software claims into reactor evidence |

## Meaning of dates

A retrieval or import date says when data was accessed. It does not establish that an operating status, performance claim or coordinate was independently verified on that date. Preserve the original source date and verification status separately.

## Definition of a release

A release may be complete for its stated dataset and interface scope while worldwide coverage remains incomplete. Unresolved gaps stay visible in this ledger and the map's [completeness statement](../05_global_reactor_map/COMPLETENESS.md). No finite release can guarantee that unpublished or newly announced devices have been captured.
